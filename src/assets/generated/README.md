# Imágenes generadas (opcionales)

Copie aquí las imágenes generadas con Higgsfield con estos nombres, sin ampliarlas:

| Archivo | Uso |
|---|---|
| `hero-salon-corredera.jpg` | Hero de la portada |
| `categoria-sistemas-aluminio.jpg` | Tarjeta principal y cabecera de «Sistemas en aluminio» |
| `categoria-materiales-adicionales.jpg` | Tarjeta y cabecera de «Materiales adicionales» |
| `categoria-otros-productos.jpg` | Tarjeta y cabecera de «Otros productos» |
| `ficha-abatibles.jpg` | Cabecera de la ficha de abatibles |
| `ficha-correderas.jpg` | Cabecera de la ficha de correderas |

`src/data/media.ts` las detecta en la compilación. Si un archivo no existe, se usa la imagen actual. Detalles en `docs/image-audit.md`.
